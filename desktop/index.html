Préférences

Langue d’interface : français. Démarrage : restaurer l’autosave si disponible.

Zoom molette · pan clic milieu ou Alt+glisser · Undo ⌘Z / Ctrl+Z · Redo ⌘⇧Z · Dupliquer ⌘D · Supprimer ⌫

IA locale prioritaire : No-de utilise d’abord Ollama sur cette machine pour générer des opérations de patch JSON. Si elle est indisponible, repli automatique sur le moteur local déterministe.

Non testée

Cloud optionnel : utilisé seulement si l’IA locale échoue et qu’un endpoint distant est activé.

Grok / xAI est exclu et sera refusé.

MIDI / Serial / OSC passent par le graphe lorsque les nodes sont connectés.

  • MIDI — console midi connect puis node MIDI Hub → sorties CC/gate. Essai matériel : à vérifier.
  • Serial — serial connect / serial reconnect / serial send …. Reconnexion auto sur ports déjà autorisés.
  • OSC — node OSC + bridge connect ws://…. Sans bridge : erreur visible, pas de faux succès.
  • Caméra — permission uniquement après action « Activer la caméra » dans l’inspecteur.
  • Whale / Blob / Threshold / Ghost / Mirror / Shadow — moteurs locaux exécutables dans le patch.
  • Audio — moteur local actif (Audio Lab, filtre, delay, FFT, Organic Audio). NDI Out utilise un relais natif et reste PLATFORM-LIMITED sans hôte compatible. Syphon/Spout ne sont pas encore exposés comme moteurs actifs.
