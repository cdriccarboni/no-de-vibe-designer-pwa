Manuel — No-de Vibe Designer

Guide simple pour créer, connecter, jouer et sauvegarder un patch. Version logicielle courante indiquée dans Préférences → Version.

1. Lancer l’application

  1. Ouvrez No-de Vibe Designer.app (build Electron autonome, Apple Silicon).
  2. Ou en développement : ./LANCER-No-de-Vibe-Designer.command puis http://127.0.0.1:4173/desktop/.
  3. Autorisez caméra / micro si le système le demande.

2. Créer et connecter des nodes

  1. Dans la Library, cliquez un node marqué exécutable (＋).
  2. Les nodes « ○ indisponible » n’ont pas encore de moteur : ils ne font pas de vrai travail.
  3. Tirez un câble d’une sortie (cercle) vers une entrée. Une incompatibilité de type est refusée avec un message clair.
  4. Double-clic sur un câble pour le supprimer. ⌫ supprime le node sélectionné. ⌘D le duplique.

Console : demo charge le patch de démonstration.

3. Sous-patches

  1. Ajoutez un node Sous-patch.
  2. Ouvrez-le (double-clic ou bouton Inspector) : le fil d’Ariane au-dessus du canvas montre Racine / …
  3. Créez des nodes à l’intérieur, connectez-les. Stage I/O fait entrer/sortir le signal du parent.
  4. Revenez à la racine via le fil d’Ariane. Tout est enregistré dans le fichier projet.

4. Audio

  • Audio Lab / Organic Audio : oscillateur Web Audio (fréquence, gain). Arrêt du node = silence, pas de traitement résiduel.
  • Mémo sonore : niveau micro. L’enregistrement fichier n’est pas encore disponible.
  • Test matériel micro : à vérifier selon permissions macOS.

5. Vibe coding

  1. Décrivez en français ce que vous voulez (ex. « caméra reliée à un shader »).
  2. Appuyez sur Entrée (Shift+Entrée = nouvelle ligne).
  3. Un aperçu des opérations s’affiche : Appliquer ou Annuler.
  4. Après application, ⌘Z annule.

Sans endpoint IA : moteur local (règles), clairement annoncé. Grok / xAI est exclu.

6. Configurer l’IA

  1. Préférences → IA / Vibe.
  2. Endpoint OpenAI-compatible + clé (stockée localement, jamais dans le dépôt).
  3. Mac série M (16 Go) : un modèle local volumineux n’est pas téléchargé automatiquement. Vous pouvez pointer vers un serveur local déjà installé (ex. Ollama) si vous le configurez vous-même.

7. Entrées / sorties

  • Caméra — node Caméra live → Preview / OUTPUT.
  • MIDI — midi connect puis node MIDI Hub. Matériel : à vérifier.
  • Serial — serial connect. Matériel : à vérifier.
  • OSC — node OSC + bridge connect ws://…. Sans bridge : erreur visible.

Max/MSP et TouchDesigner : pas d’import/exécution native universelle. Seuls des bridges / génération partielle sont prévus ; les nodes « Bridge » restants sont encore indisponibles.

8. Sauvegarder et rouvrir

  1. Enregistrer → fichier .cvd.json.
  2. Autosave navigateur / profil Electron.
  3. Fermez complètement l’app, rouvrez : le patch (nodes, câbles, sous-patches, paramètres) doit revenir.

9. Dépannage

  • Caméra noire → permissions Système → Confidentialité.
  • Câble rouge → types incompatibles ou node indisponible.
  • OSC silencieux → bridge WebSocket requis.
  • App non signée → Gatekeeper peut demander un clic droit → Ouvrir.

Manuel aligné sur la version livrée — mis à jour avec le logiciel.
