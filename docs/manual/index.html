Manuel — No-de Vibe Designer

Guide simple pour démarrer. Vocabulaire de base, sans jargon inutile.

1. Qu’est-ce que c’est ?

No-de Vibe Designer est un environnement pour créer un patch : des briques (nodes) reliées entre elles, qui traitent la vidéo, le son et les commandes de scène.

2. Lancer l’application

  1. Double-cliquez LANCER-No-de-Vibe-Designer.command ou ouvrez l’app macOS.
  2. L’interface Bureau s’ouvre : Library à gauche, Patch au centre, Preview à droite.

3. Chaîne de base (caméra → shader)

  1. Ajoutez Caméra live (marquée exécutable).
  2. Ajoutez Shader Lab.
  3. Tirez un câble de la sortie video vers l’entrée texture.
  4. Autorisez la caméra si demandé. La Preview doit afficher l’image + le voile shader.
  5. Cliquez OUTPUT ↗ pour une fenêtre de diffusion.

Astuce console : tapez demo puis Entrée pour charger ce patch.

4. Vibe coding

Dans la zone Vibe, décrivez ce que vous voulez. Entrée envoie la commande (Shift+Entrée = nouvelle ligne).

  • Si un endpoint IA est configuré (Préférences → IA / Vibe) : appel réel.
  • Sinon : moteur local (règles) — clairement indiqué dans la console.
  • Jamais de faux « succès IA » si le moteur est indisponible.

5. Sauvegarder et rouvrir

Enregistrer crée un fichier .cvd.json. À la réouverture (ou via autosave), le patch — nodes et connexions — est restauré, puis la caméra / lecture reprennent.

6. MIDI, OSC, Serial

  • Logiciel : les nodes MIDI / OSC reliés au graphe font circuler des valeurs (ex. CC → intensité shader).
  • Matériel : branchez l’appareil, puis midi connect / serial connect / bridge connect ws://…. Tant que non testé sur machine réelle : à vérifier.

7. Nodes disponibles vs indisponibles

Seuls certains nodes sont exécutables (caméra, shader, midi, osc, tracking, stage I/O). Les autres restent visibles dans la Library mais sont marqués indisponibles — ils ne font pas encore de vrai travail.

8. Mode Plateau

Masque Library, Inspector et Vibe pour se concentrer sur Preview + Timeline pendant une répétition.
