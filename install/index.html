Installation macOS
  1. Télécharge le DMG Universal.
  2. Ouvre-le puis glisse No[co]de Vibe Designer dans Applications.
  3. Lance l’application depuis Applications.
  4. Si Gatekeeper bloque la première ouverture : Réglages Système → Confidentialité et sécurité → Ouvrir quand même. Aucun Terminal n’est nécessaire.
Pourquoi garder Apple Silicon / Intel séparés ?

Ce sont des paquets de secours utiles au diagnostic. Le paquet Universal reste le téléchargement recommandé.
