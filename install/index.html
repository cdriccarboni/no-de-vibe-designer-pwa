À savoir

Quel format choisir pour essayer No[co]de ?

La PWA est le moyen le plus immédiat. Pour un usage régulier en répétition ou en spectacle, la version desktop de ton système offre une fenêtre autonome et une installation plus classique.

Mes projets passent-ils d’un système à l’autre ?

Oui : les variantes utilisent le même format de projet No[co]de. Les fonctions qui dépendent d’un matériel ou d’une API système peuvent évidemment varier selon la machine.

Pourquoi macOS ou Windows peuvent-ils afficher un avertissement ?

No[co]de est distribué sans abonnement de signature commerciale Apple et les builds communautaires Windows peuvent aussi être inconnus des systèmes de réputation. Utilise uniquement les fichiers provenant de la release GitHub officielle liée ici.
